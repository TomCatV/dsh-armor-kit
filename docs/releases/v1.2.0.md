## 真跑暴露并修掉的 5 个 bug

这些是**只跑一次冒烟才会暴露**的：

| # | 问题 | 根因 | 修法 |
|---|---|---|---|
| 1 | `python:3-slim` 镜像没拉，`docker run` 静默失败 | 输出被 `Out-Null` 吞掉 | 预拉镜像 + 显式捕获 run 错误 |
| 2 | 靶标和 kali 跨网络不通 | 靶标在 `armor-smoke-net`，kali 在默认 bridge | 测试时把 kali 接入同网，测完断开 |
| 3 | sqlmap 没出数据 | 用了 `--dbs` 而非 `--dump` | 改 `--dump`，直接拿到 FLAG |
| 4 | `/work` 落盘找不到文件 | **老容器挂的是 `D:\AI\newPJ\kali`，脚本假设 `~\.dsh\kali`** | 从容器实测挂载点，不假设路径 |
| 5 | `impacket-krbrelayup` pip 装不上 | 它不是 pip 包，是独立工具 | 从 pip 行移除 |

`kali-setup.ps1` 现在会检测挂载点不一致并告警（提示 `-Force` 重建）。

## 完整流程（v1.2.0）

```powershell
git clone https://github.com/TomCatV/dsh-armor-kit.git
cd dsh-armor-kit

.\scripts\install.ps1        # purge + 注入 + Kali 一次装完
.\scripts\restart-dsh.ps1    # 重启宿主（必须）
.\scripts\verify.ps1         # 运行时实测 + Kali 工具链自检
.\scripts\smoke.ps1          # 全链路冒烟（8 项）
```

装完说「**甲来**」进状态，`kali nmap ...` 直接开扫。
