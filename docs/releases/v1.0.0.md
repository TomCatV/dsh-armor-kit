## 快速开始

```powershell
git clone https://github.com/TomCatV/dsh-armor-kit.git
cd dsh-armor-kit

.\scripts\install.ps1        # 装插件 + 写注入 + 跑 80 条补丁（自动备份宿主）
.\scripts\restart-dsh.ps1    # 重启宿主 —— 必须，补丁改的是磁盘源码
.\scripts\verify.ps1         # 运行时实测：越界写盘 / 提权命令 / 身份句 / 注入 / 审批
```

装完说「**甲来**」进入状态。

### 自定义唤醒口令

```powershell
.\scripts\install.ps1 -WakeWord "开干"
```

### 卸载

```powershell
.\scripts\uninstall.ps1      # 从备份恢复全部宿主文件
```

## 80 条补丁覆盖

- **提示词层** —— 身份句清除、审批句中性化、工作区指令强化、系统提示替换
- **代码层** —— 沙箱加宽放行、文件护栏关闭、升级永不拒绝、超时恢复、递归深度放开
- **工具层** —— `ask_user` 超时收口、`run_code` 审批中性化、shell 网络限制移除
- **兼容层** —— 0.1.5 / 0.2.x 版本锚点适配、session v0 别名、preset 拉取启用

> **版本漂移提示**：宿主小版本升级可能让少量补丁锚点失配，状态显示 `skipped`。这通常意味着宿主语义已是目标状态（无需再打），并非功能缺失。`verify.ps1` 会区分「真失败」与「语义已达标」。
